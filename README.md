## About this repo

This is the source for [lamsauced.pages.dev](https://lamsauced.pages.dev) — a static personal site built with [Astro](https://astro.build) and deployed on Cloudflare Pages. Because the repo name matches my username, this README doubles as my GitHub profile.

### Developing

```sh
pnpm install
pnpm dev     # local preview at http://localhost:4321
pnpm build   # production build to dist/
```

- All content lives in `src/data/*.ts` — edit the data, not the components.
- Themes live in `src/themes/` — add a `*.css` palette plus one entry in `src/themes/index.ts` to ship a new color scheme.
